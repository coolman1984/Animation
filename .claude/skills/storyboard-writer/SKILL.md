# storyboard-writer
Operating policy: `studio/WORKFLOW.md`; load only the relevant department via `studio/SKILLS.md`.


Read CRAFT_GUIDE.md sections Direction and content / Elegant Egyptian copy.
Create one table: interval → purpose → asset/evidence → framing → copy/readable interval → transition → sound cue.
Use the number of shots the message needs; no 7–14 shot quota. Align meaningful moments with musical phrasing, not every scene to a bar.
Each scene adds a fact, detail or feeling. Confirm claims; mood boards never prove ingredients, origin dates or brand spelling.
Read Egyptian copy aloud: short, warm, specific, no forced slang, unsupported superiority or translated corporate phrases.
Use production.json as the shared timing source for film.js and score.mjs. Keep actual readable holds separate from animated entrances.
Preflight checks missing assets, evidence references, timeline gaps and basic copy issues. Actual legibility and persuasion need visual/audio review.
