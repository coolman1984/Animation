# platform-delivery
Operating policy: `studio/WORKFLOW.md`; load only the relevant department via `studio/SKILLS.md`.


Common starting layouts: feed 4:5 1080×1350, Reels/Stories 9:16 1080×1920; requested duration takes priority.
Use H.264/yuv420p/bt709, AAC 48kHz and faststart. The studio's −14 LUFS/−1.5dBTP targets are not official Meta mandates.
Verify changing placement requirements in official docs when delivering. Do not repeat unsourced muted-viewing percentages,
universal winning durations, file caps or historical safe-zone percentages as current platform facts.
Each delivery has w,h,safe, optional segments/variant. Check the actual placement UI overlay; treat existing film2 safeRect as a conservative project choice.
Recompose focal point, type and CTA for each ratio; don't just crop a finished feed render. Check affected ratios after shared layout edits.
Use --profile=final. Captions/thumbs/share extras currently include legacy name-specific branches; see README, don't assume every new name gets all extras.
Final report links actual files and any unverified platform behavior. Upload/publishing requires the owner's task authorization.

**60 fps share copies (showreel2):** a 15 s 1080p60 master was 13.6 MB; the 2-pass share copy targeted 12 MB and came out at 10.5–11 MB. Check the share copy's size and a 1:1 crop; it was not reviewed by the critic — say so if true.
