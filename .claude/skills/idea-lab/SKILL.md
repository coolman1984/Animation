# idea-lab
Operating policy: `studio/WORKFLOW.md`; load only the relevant department via `studio/SKILLS.md`.


Skip if the owner has already chosen the idea. Otherwise write up to THREE cards:
viewer insight → first-frame hook → single promise → available proof → visual motif → CTA → production risk.
Pick the strongest feasible idea; state one sentence why. Do not generate 30 variants or arbitrary numeric taste scores.
A product-led hook can contain a logo. Avoid a logo-only delay before the viewer understands the offer.
Platform durations and success rates are not universal; use the requested placement and confirm current requirements only when needed.
If a concept requires unavailable footage, choose a feasible treatment or record the missing input. Never fabricate proof.
