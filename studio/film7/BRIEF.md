# BRIEF — Film 7 · PIXEL Plus «ريل الموشن» (20 s, 9:16 Reels, one delivery)

**Owner request (2026-10-02):** a second reference video was supplied — «do one like this, 20 seconds, in Arabic, new music and a
very attractive new rhythm». Plus: *make a dynamic 20-second motion-graphics video that shows what an incredible motion designer you
are, like a showreel for a résumé about your innovation in this topic of the ad. Go all out.* The topic is the agency's own craft:
motion design for ads. Reverse-engineer the reference first.

**Reference (private pack `references/showreel3-ref/`, not in git):** 15.3 s, 916×826 @ 60 fps screen recording, 120 BPM, E major /
Hijaz-flavoured house groove, no voice. It is a UI micro-interaction reel: ONE black rounded box on a warm off-white canvas morphs
between interface states while a cursor drives it — «Generate» button → music-player card → volume slider → toggle switch →
Day/Week/Month segmented control → stats card (counting number + drawn line + tooltip) → search palette that types «frame» →
button → check mark. Measured: morphs last 0.2–0.4 s with 1.5–2 s calm holds; content blurs out/in around the morph; the cursor
arrives on every interaction; one state per bar. Not reused: its copy, icons, gradient album art, numbers, music.

**For whom:** an Egyptian business owner or creative director who has 20 seconds and wants proof that this agency can really do motion.
**Promise:** motion designed down to the spring, the curve and the beat. **Evidence:** the reel itself; each state demonstrates a technique the
studio actually performs; the stats card is labelled «مثال توضيحي» (no invented results). **CTA:** «ابدأ مشروعك — ابعتلنا رسالة» (no phone number / URL invented).

**Direction — one gesture:** the same black box morphs through eleven interface states (one per bar at 144 BPM), driven by a cursor with a
3-D tilt. The reel's own timeline is the player's progress bar; a chapter timeline runs along the bottom; a ghost chapter numeral
fills the lower third. Beyond the reference: a live-reflowing aspect-ratio frame (9:16 → 1:1 → 16:9 → 4:5 on four beats), an easing-curve editor whose ball
runs the curve the cursor just drew, a full-screen type scene on four hits (whip / flip / punch / rise), a check that opens a
pixel iris into the brand card, and the PIXEL Plus character standing on the wordmark.
Type: Alexandria 800/600 + Aref Ruqaa Bold accent words + IBM Plex Sans Arabic labels. Palette: warm paper, ink black, brand blue, gold, white.
