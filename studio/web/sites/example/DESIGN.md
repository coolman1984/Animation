# Arabic menu example

## A. Direction
A fictional cafe menu for testing Arabic reading and navigation. No real business, booking, roast schedule or customer claims. Main task: read the drink list.

## B. System
Existing clay palette, two Arabic-capable type families maximum. Plain CTA, opaque header, collection readable on narrow screens. No stock decorative icons.

## C. Behavior
Native horizontal list, static text, no autoplay. No-JS and reduced-motion retain all drinks and navigation. No 3D inspection needed for this menu.

## D. Review
Real Chromium audit at phone/tablet/desktop and reduced motion found no red lights; new no-JS/reduced-motion regression passes. See ../../ANTI_SLOP_AUDIT.md for scope and limits. No real device or customer study.
