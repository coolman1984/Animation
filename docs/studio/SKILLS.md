النسخة الأصلية للمهارات في `.claude/skills/`. لو اتغيّر سلوك مهارة، حدّث الأصل والفهرس واعمل مزامنة من جذر المستودع:

```sh
node studio/studio.mjs agents --sync
```

راجع [سجل التقنيات](../../studio/TECH_RADAR.md) و[كتالوج الأدوات](../../studio/toolkit/README.md) قبل الاعتماد على أداة خارجية. حالة كل قدرة في [السجل](../../studio/capabilities.json)، واختبار الجهاز هو دليل توفرها عليه.
