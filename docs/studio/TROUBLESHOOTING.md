# المشاكل والحلول 🔎

| العلامة اللي ظهرت | أول خطوة | إزاي تتأكد إنها اتحلت؟ |
| --- | --- | --- |
| الموقع بيرفض البناء أو المراجعة | كمّل أقسام التصميم في ملف المشروع. وضع المسودة مفيد للتجربة فقط | أعد الفحص العادي بعد إكمال [مسار التصميم](../../studio/web/WEB.md) |
| الموقع شكله عام أو الخط والرسالة ضعاف | اختَر مراجع ملائمة وحدّد وظيفة كل جزء. راجع أول شاشة، التسلسل البصري والإجراء الأساسي | قارن صور قبل وبعد على مقاسات مختلفة، وجرّب الإجراء بإيدك. [دروس المعرض](../../studio/web/gallery/LESSONS.md) |
| التصدير وقف أو الذاكرة خلصت | راجع سجل البناء. اتبع المسار المعتمد للمشروع وسياسة الذاكرة، وسيب مهمة تصدير واحدة شغالة | راجع اكتمال المخرجات وبوابات التحقق، وافتح الملف النهائي. [دليل التشغيل](../../studio/WORKFLOW.md) |
| الحركة متقطعة أو الجودة غير مقنعة | راجع مشهد قصير وحدّد السبب المحتمل. افصل اختبار زمن الإطار عن مراجعة الإضاءة والخامات وتكوين اللقطة | قارن نفس اللقطة أو التفاعل قبل وبعد على الجهاز المستهدف. [معايير الإخراج](../../studio/QUALITY_PLAYBOOK.md) |
| نص عربي متقصوص أو الصوت بيغطي الكلام | جرّب أطول سطر على المقاس المطلوب، وراجع خط العربي وخفض الموسيقى وقت الكلام | اقرأ الملف النهائي على شاشة صغيرة واسمعه بسماعة الموبايل. [الصوت](../../studio/VOICE_STUDIO.md) · [الترجمة](../../.claude/skills/subtitles-rtl/SKILL.md) |

لو المشكلة جديدة، سجّل خطوات تكرارها، الجهاز والإصدار، الدليل، السبب بعد إثباته، الإصلاح وطريقة اختباره. سجّل الحل العام في [وصفات التنفيذ](../../studio/TECHNIQUES.md)، وتفاصيل الحالة في سجل المشروع.
