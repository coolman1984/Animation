# إدارة التوثيق والتسليم 📚

| المعلومة | مكانها الأساسي | إمتى تتحدّث؟ |
| --- | --- | --- |
| الشغل الجاري والنتيجة وحدود التحقق | [حالة الاستوديو](../../STATUS.md) | عند التسليم أو التعطّل |
| إيه اتغيّر وإمتى | [سجل التغييرات](../../studio/CHANGELOG.md) | مع التغيير نفسه |
| قرار مهم وأسبابه | ملف تصميم الموقع أو سجل الفيلم، ورابط من [المحطات](HISTORY.md) لو القرار عام | عند اعتماد القرار أو استبداله |
| درس من تجربة وحل قابل للتكرار | [الدروس](../../studio/CRAFT.md) و[الوصفات](../../studio/TECHNIQUES.md) | بعد التحقق على مشروع فعلي |
| مصادر المواد وحقوقها | [سجل الأصول](../../studio/ASSETS.md) للمشترك وملف الحقوق للمشروع | عند إدخال أصل أو تغييره |
| قواعد متكررة للمساعدين | [المهارات](SKILLS.md) و[تعليمات العمل](../../AGENTS.md) | عند تغيّر القاعدة وتوفر دليل |
| تفاصيل مشروع واحد | ملف تصميم الموقع أو موجز وسجل الفيلم | من بداية المشروع لحد التسليم |

اكتب الحالة بوضوح. «مقترح» قبل التنفيذ، «مسودة» عند وجود نسخة للمراجعة، «متحقق» مع ذكر نطاق الاختبار، «مسلّم» مع رابط الناتج، و«متعطّل» مع السبب والخطوة التالية. احتفظ بالقرار القديم واربطه بالبديل لو اتغيّر.

## قالب سجل المشروع

انسخ البنود في ملف المشروع الموجود. الروابط للنتائج والأدلة جزء من السجل.

```markdown
# اسم المشروع
- النوع والمسؤول والتاريخ والحالة
- الجمهور والهدف والإجراء المطلوب من الجمهور
- التسليم المطلوب والمنصة والمقاس والمدة
- المراجع المختارة وسبب الاختيار ومصادر الأصول وتراخيصها
- تسلسل الشاشات أو المشاهد والإخراج والصوت
- أهم قرار وسببه والبدائل اللي اتدرست
- معيار القبول والجهاز أو مقاسات العرض
- المشاكل، خطوات التكرار، الإصلاح ودليل التحقق
- رابط المسودة أو التسليم، نتيجة المراجعة، وما يحتاج متابعة
- درس قابل لإعادة الاستخدام ومكان تسجيله
```

قبل قفل الشغل، اربط النتيجة والدليل بالحالة الحالية، وحدّث الأدلة اللي اتأثرت، وافحص التوثيق:

```sh
node --test studio/test/docs.test.mjs
```
