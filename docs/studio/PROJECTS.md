## بداية الموقع

من جذر المستودع، استخدم اسم مشروع جديد وبدّل بيانات المثال:

```sh
node studio/studio.mjs web plan demo-site --brand=Demo --lang=ar --style=paper-editorial --cta="اطلب عرض سعر" --problem="صعوبة اختيار الخدمة" --promise="خدمات واضحة وأسعار مفهومة"
```

افتح `studio/web/sites/demo-site/DESIGN.md` وكمّل التوجيه الفني، نظام التصميم، الحركة والمراجعة طبقًا [لدليل المواقع](../../studio/web/WEB.md). بعد تجهيز المحتوى والتصميم:

```sh
node studio/studio.mjs web build demo-site
node studio/studio.mjs web check demo-site
```

راجع الإجراء الأساسي، وضوح العربي، لوحة المفاتيح وتقليل الحركة على الموبايل والتابلت والكمبيوتر. لو بتطوّر موقع قائم، استخدم التدقيق قبل وبعد من الدليل نفسه.

## بداية الفيديو

1. راجع [سياسة الإنتاج](../../studio/AUTONOMOUS_FILM.md) و[أسلوب الإخراج](../../studio/QUALITY_PLAYBOOK.md)، وسجّل المنصة والمقاس والمدة المطلوبة. اختَر لقطة أو مشهد قصير للمراجعة الأولى.
2. اتبع [دليل محرك الأفلام](../../studio/studio-engine/STUDIO.md) لإنشاء `spec.json` وفحصه وإخراج لقطات ثابتة ومعاينة. استخدم [أمر بناء الاستوديو](../../studio/WORKFLOW.md) لمسارات الأفلام اللي بتشتغل بالأمر ده، واتبع أمر المحرك الموثّق لمشروعات المواصفات.
3. ابحث عن الصوت بالطريقة المعتمدة في [تعليمات الاستوديو](../../AGENTS.md) وسجّل الترخيص. شغّل تصدير واحد في المرة، وشاهد الملف النهائي بسرعة عادية وراجع الصوت والترجمة والمقاس قبل التسليم.
