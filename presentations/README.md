# Presentations section / قسم العروض التقديمية

## English
**What it does:** Presentation tools hub: 10 open-source deck/motion tools plus Arabic docs.

**Where it lives:** a separate **private** repo, linked here as a pointer only: <https://github.com/coolman1984/presentation-studio> (branch `main`).

**Why a pointer and not a submodule/copy:** this repo is public and `presentation-studio` is private. A submodule would break clones for anyone without access and could expose its contents. The linked repo is not copied, deleted or altered.

**Relations:** produces decks and slide-based content; uses the brand identity from `../design-canva/`; outputs can be distributed by `../content-factory/`; shares motion ideas with `../animation/`.

## العربي
**بيعمل إيه:** مركز أدوات العروض: ١٠ أدوات مفتوحة المصدر للعروض والحركة ومعاها شرح بالعربي.

**مكانه:** ريبو منفصل **خاص**، متوصّل هنا بمجرد رابط: <https://github.com/coolman1984/presentation-studio> (فرع `main`).

**ليه رابط مش submodule ولا نسخة:** الريبو ده عام، وريبو العروض خاص. الـ submodule هيبوظ الاستنساخ لأي حد مالوش صلاحية. ريبو العروض ما اتنسخش ولا اتمسح ولا اتعدّل.

**علاقته بالباقي:** بيطلّع العروض، وبياخد هوية البراند من `../design-canva/`، و«مصنع المحتوى» بيوزّع ناتجه، وبيتشارك أفكار الحركة مع `../animation/`.
